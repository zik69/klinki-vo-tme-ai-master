# Задача task-001: Перегенерация книги правил в Markdown

## Что хочет пользователь и зачем

Я, как разработчик, хочу перевести книгу правил «Клинки во тьме» из PDF в Markdown, чтобы ИИ-мастер мог читать и использовать правила.

## Что входит в работу

- Извлечь текст из PDF книги «Клинки во тьме» (384 страницы).
- Сохранить структуру: главы, разделы, списки, таблицы.
- Разбить на удобные `.md`-файлы по главам/разделам.
- Проверить, что текст полный и читаемый.

## Как понять, что готово

- Все страницы книги переведены в Markdown.
- Заголовки, списки и таблицы оформлены корректно.
- Файлы открываются в любом редакторе и читаются без ошибок.
- Нет потерянных страниц или пустых разделов.

## Что в эту задачу не входит

- Перевод дополнения «Мстители» (отдельная задача).
- Формирование базы знаний для ИИ-мастера (task-002).
- Создание веб-приложения (task-003).

# Задача task-003: Каркас веб-приложения

## Что хочет пользователь и зачем

Я, как игрок, хочу открыть игру в браузере и увидеть начальный экран, чтобы начать кампанию.

## Что входит в работу

- Создать минимальный веб-каркас: index.html, стили, скрипт.
- Начальный экран с названием игры и кнопкой «Начать».
- Подготовить структуру папок для дальнейшей разработки (css, js, assets).
- Убедиться, что страница открывается в браузере без ошибок.

## Как понять, что готово

- Файл index.html открывается в браузере.
- Виден заголовок «Клинки во тьме» и кнопка начала.
- Нет ошибок в консоли браузера.
- Структура папок готова для следующих задач.

## Что в эту задачу не входит

- Создание банды и персонажей (task-004).
- Логика игры и ИИ-мастер (task-009).
- Сохранение прогресса (task-008).

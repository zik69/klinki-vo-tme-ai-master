# Задача task-004: Создание банды из 4 персонажей

## Что хочет пользователь и зачем

Я, как игрок, хочу собрать команду из 4 персонажей с навыками и страстями, чтобы играть за банду.

## Что входит в работу

- Реализовать полное создание персонажа по правилам книги (происхождение, прошлое, 3 навыка, талант, страсть).
- Добавить шаблоны (прегены) для быстрого старта.
- Собрать банду из ровно 4 персонажей.
- Показать список банды с именами и навыками.

## Как понять, что готово

- Игрок может создать 4 персонажей вручную или выбрать шаблон.
- Банда отображается на экране.
- Данные сохраняются в памяти (локально).

## Что в эту задачу не входит

- Сохранение в браузере (task-008).
- ИИ-мастер (task-009).
- Ход на дело (task-006).

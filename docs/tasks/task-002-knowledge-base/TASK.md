# Задача task-002: База знаний для ИИ-мастера

## Что хочет пользователь и зачем

Я, как разработчик, хочу структурировать правила в базу знаний (разделы, таблицы, примеры), чтобы ИИ-мастер отвечал точно и по делу.

## Что входит в работу

- Проанализировать Markdown-файлы книги в `docs/rules/`.
- Выделить ключевые разделы: создание персонажа, навыки, проверки, дело, передышка, мистические силы, Дасквол.
- Создать структурированную базу знаний (JSON или Markdown с чёткими заголовками и таблицами).
- Убедиться, что база покрывает основные правила и примеры.

## Как понять, что готово

- База знаний содержит основные разделы правил.
- Таблицы навыков, действий, напастей и активов приведены в удобном виде.
- ИИ-мастер может ответить на типовые вопросы по правилам, используя базу.
- Файл базы знаний открывается и читается без ошибок.

## Что в эту задачу не входит

- Перевод дополнения «Мстители» (отдельная задача).
- Создание веб-приложения (task-003).
- Генерация NPC и локаций (бэклог).
